# Original GridBlast listing artwork

These are **promotional graphics**, not captured gameplay screenshots or evidence of approved Play Store publication.

| Draft asset | File | Format |
| --- | --- | --- |
| Feature graphic | [gridblast-feature-1024x500.png](gridblast-feature-1024x500.png) | 1024×500, PNG RGB (24-bit, no alpha) |
| Listing icon | [gridblast-icon-512x512.png](gridblast-icon-512x512.png) | 512×512, PNG RGBA (32-bit), under 1024 KB |

The graphics use GridBlast's dark navy, cyan, yellow, violet and blue palette and an original six-tile brand glyph to match the Android launcher concept. The feature image shows abstract block-puzzle imagery **as an illustration**, not a screenshot of the current UI. Do not submit it as one of the required actual app screenshots.

Run `python3 scripts/verify-store-assets.py` from the repository root to check structural PNG format, dimensions, bit depth, uncompressed scanlines and icon size. CI runs this validator. Passing structural checks **does not** prove visual polish, trademark clearance or policy approval.

**Before publishing:** open and review each image visually, verify all text/contrast/cropping and ownership, capture at least two **unaltered, real** gameplay screenshots from a device running the submitted version, and compare the current Play Console upload rules. The owner must approve final artwork.
